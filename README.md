A basic Spring(Boot) MVC & SSR web app for management of flights.

Internationalized (en sr ru de fr).
W/o ORM.
W/o Spring Security.

Tools & technologies used:
--------------------------
MySQL 8.0,
Java 8, 
Spring(boot), 
Thymeleaf, 
HTML 5, 
CSS 3, 
JS (AJAX & fetch async requests to server), 
JQuery.
